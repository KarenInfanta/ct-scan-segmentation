# CT Scan Segmentation — Research Portfolio

A responsive, single-page portfolio case study for a CT image segmentation research project.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `ct-scan-segmentation`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. After deployment, open the Pages URL shown in Settings → Pages.

## Before sharing with recruiters
- Add the actual implementation/source code and a reproducible notebook if available.
